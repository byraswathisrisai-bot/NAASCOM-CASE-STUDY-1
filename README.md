# 🔋 Smart Electric Vehicle Battery Performance Analysis

 Overview

This project analyzes **Electric Vehicle (EV) battery performance** using Python. The analysis uses battery sensor readings such as **temperature, voltage, current, and charge percentage** to understand the battery's performance and identify possible unsafe conditions.

This case study applies **Python Basics, NumPy, Linear Algebra, and Calculus** to analyze the battery data.

## 📊 Parameters Analyzed

* 🌡️ Temperature (°C)
* ⚡ Voltage (V)
* 🔌 Current (A)
* 🔋 Battery Charge (%)

## 🛠️ Technologies Used

* Python
* NumPy
* Linear Algebra
* Calculus

## 📚 Analysis Performed

### 1. Python Basics

* Displayed battery sensor readings
* Identified high-temperature readings
* Identified low-battery readings
* Created a battery status function

### 2. NumPy Analysis

* Created a NumPy array
* Found array shape
* Calculated average temperature, voltage, current, and charge
* Found maximum and minimum temperature
* Extracted voltage data
* Identified high-temperature and low-battery readings

### 3. Linear Algebra

* Matrix multiplication
* Transpose
* Determinant
* Matrix inverse
* Solving a system of equations using NumPy

### 4. Calculus

* Calculated the rate of change of battery charge
* Calculated discharge rates at different times
* Analyzed the change in discharge rate



 Purpose

This project was created as a case study assignment to practice applying Python programming and mathematical concepts to a real-world EV battery analysis problem.
